# LensTracker 1.2.0

같은 렌즈의 EXIF 표기 차이(제조사 접두어, 공백, 조리개 슬래시, Sigma Art 표기)는 자동으로 통합합니다. 기존 사진 연결과 메모를 보존하며 렌즈·카메라 조합 통계 및 사진당 비용도 합쳐 계산합니다. 세대·조리개·모델이 다른 렌즈는 구분합니다.

렌즈 참고 가격은 제공된 `렌즈가격.json`의 46종을 사용합니다. 범위 가격은 **최고가**를 계산에 적용하고 원래 범위를 장비 메모에 보존합니다. 새로 인식된 렌즈와 가격 미입력 장비에 자동 적용하며, 직접 수정한 가격은 유지합니다. 제조사·공백·로마숫자 표기 차이를 맞추되 모델이 불명확하거나 가격표에 없으면 미입력으로 둡니다.

릴리스: **1.2.0 · 2026-09-12**. 버전별 변경 사항은 [변경 이력](CHANGELOG.md)을 확인하세요.



**독립 앱 실행: 프로젝트 폴더의 `Garden_Tools_LensTracker.exe`를 더블클릭하세요.** 지정한 `icon.png` 아이콘이 적용된 실행 파일이며, `dist\LensTracker\LensTracker.exe`를 열어 자체 창으로 실행합니다. 프로젝트의 `dist` 폴더를 함께 유지하세요. Python이나 브라우저 설치가 필요하지 않습니다. `start.cmd`와 `start.ps1`도 이 실행 파일을 우선 사용합니다. 다른 PC에는 `dist\LensTracker-1.2.0-Windows-x64.zip`을 전달하고 전체 압축을 풀어 사용합니다. `dist\LensTracker-Windows-x64.zip`도 같은 최신 배포본입니다. 자세한 실행·데이터 이전·재빌드 안내는 [DESKTOP.md](DESKTOP.md)를 확인하세요.

## 개발용 웹 모드 실행

웹 모드를 개발하려면 Python 3.11 이상 환경에서 `requirements.txt`를 설치한 다음 아래 명령을 사용합니다. 일반 사용자는 위의 독립 앱 실행 방법을 사용하세요.

```powershell
.\.venv\Scripts\python.exe app.py
```

주소: **http://127.0.0.1:5273**. 종료하려면 실행 창에서 Ctrl+C를 누릅니다. 포트가 사용 중이면 `app.py --port 5274`로 실행하세요. 자동 브라우저 열기를 끄려면 `--no-browser`를 추가합니다.

다른 환경에서는 `python -m venv .venv` 후 가상환경에서 `python -m pip install -r requirements.txt`, `python app.py`를 실행할 수 있습니다.

## 사용 순서

1. **사진 가져오기**를 누르고 폴더를 선택하면 해당 폴더와 모든 하위 폴더의 사진을 자동으로 검색합니다. 경로를 직접 입력할 때는 가져오기 화면에서 분석 시작을 누릅니다.
2. **장비와 가격**에서 신품 가격을 입력합니다. 실제 구입 가격과 가격 출처/확인일도 선택 입력할 수 있습니다.
3. **개요**에서 카메라·렌즈·조합 순위, 월별 추이, 초점거리, 가격 배분 비용을 확인합니다.
4. 촬영일/카메라/렌즈로 필터링하고 **CSV 내보내기**를 누릅니다.

사진 메타데이터와 열었던 폴더 목록은 자동 저장됩니다. 다음 실행에서는 저장된 통계를 바로 표시하고, 가져오기 화면에서 마지막 폴더와 저장된 폴더 목록을 복원합니다. 같은 폴더를 다시 분석하면 변경되지 않은 사진은 파일 내용과 EXIF를 다시 읽지 않고 건너뛰며, 새로 추가되거나 변경된 사진만 처리합니다.

**CSV 기록**에서는 LensTracker의 `lenstracker-stats.csv`를 가져와 장비·조합별 촬영 수, 비율, 가격과 사진당 비용을 보관하고 조회합니다. 파일을 선택하거나 경로를 입력해 가져올 수 있으며, 같은 내용의 파일은 중복 저장하지 않습니다. 저장 후에는 원본 CSV가 없어도 기록을 볼 수 있습니다. 이 CSV는 집계 파일이므로 사진별 경로·촬영일·EXIF를 복원하지 않으며, 기존 사진 수와 장비 가격에 합산하거나 덮어쓰지 않습니다.

예시 미리보기는 가상의 사진·가격이며 실제 데이터베이스에 저장되지 않습니다.

## 사진당 비용

- 장비 단가 = 신품 가격 ÷ 해당 장비 사진 수.
- 조합 단가 = 카메라와 렌즈 신품 가격 합 ÷ 해당 조합 사진 수. 순위 화면에서는 적용된 필터의 사진 수를 사용합니다.
- 상단 평균 배분 비용 = 전체 라이브러리에서 계산한 카메라 단가와 렌즈 단가의 합을, 선택 사진 중 두 가격이 모두 있는 사진에 대해 평균한 값입니다. 가격이 입력된 비율도 함께 표시됩니다.
- 장비 관리 화면과 등록 가격 합계는 전체 라이브러리 기준입니다. 미상 장비나 미입력 가격은 0원으로 간주하지 않습니다.

장비 가격을 사진 수로 나눈 참고 지표이며 실제 총지출이나 감가상각액이 아닙니다. 사진 수는 등록된 고유 파일 수이고 실제 셔터 작동 횟수와 다릅니다.

## 파일 지원

JPEG, TIFF, PNG, WebP는 기본 지원합니다. 카메라가 렌즈 모델을 표준 EXIF에 저장하지 않으면 렌즈는 미상으로 나올 수 있습니다.

RAW/HEIC 및 제조사 메타데이터를 읽으려면 [ExifTool 공식 사이트](https://exiftool.org/)의 배포본을 설치하세요. Windows 배포본의 실행 파일을 `exiftool.exe`로 지정하고 동봉된 지원 폴더를 유지해야 합니다. 다음 중 하나로 연결합니다.

- PATH에 `exiftool` 등록
- 이 프로젝트의 `tools/exiftool.exe`에 배치
- 환경변수 `EXIFTOOL_PATH`에 실행 파일의 절대 경로 지정

가져오기 화면에서 도구 감지 상태를 확인할 수 있습니다. ExifTool 미설치 상태의 RAW/HEIC는 오류 목록에 남고, 설치 후 재스캔하면 다시 처리됩니다. 지원 확장자라도 손상되었거나 해당 메타데이터가 없으면 읽기 실패 또는 미상으로 처리합니다. RAW는 원본 미리보기를 생성하지 않습니다.

SHA-256이 같은 파일은 한 번 집계합니다. 내용이 다른 RAW+JPEG 쌍·보정본·리사이즈본은 각각 집계합니다. 재스캔에서 경로/크기/수정시각이 같으면 건너뜁니다. 외부에서 삭제된 파일 기록은 자동으로 삭제되지 않는 누적 라이브러리입니다. 같은 모델의 여러 실물 장비는 하나로 묶입니다.

## 데이터와 개인정보

사진은 읽기만 하고 외부로 전송하지 않습니다. 독립 앱은 메타데이터·원본 경로·장비 가격·열었던 폴더를 **`LensTracker.exe` 옆의 `data/lenstracker.sqlite3`**에 저장합니다. 개발용 실행은 프로젝트의 `data/lenstracker.sqlite3`를 사용합니다. GPS와 사진 바이너리는 저장하지 않습니다. 앱을 종료한 후 `data` 폴더를 복사하면 백업할 수 있으며, 앱 업데이트 시 이 폴더를 유지하세요. 이전 버전의 `%LOCALAPPDATA%\LensTracker` 기록은 새 데이터 파일이 없을 때 원본을 보존한 채 자동 복사합니다. 환경변수 `LENSTRACKER_DATA_DIR`로 데이터 경로를 바꿀 수 있습니다.

서버는 127.0.0.1에만 바인딩합니다. CDN·외부 폰트·분석 추적기는 없습니다. 초기 의존성 설치 이후 기본 기능은 오프라인으로 실행됩니다. 개인 PC용이며 다중 사용자 서버 배포용 인증 기능은 포함하지 않습니다.

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

실제 EXIF 테스트 이미지, 중복/변경 파일 처리, 가격 누락과 0원, 비용 수식, 필터, CSV, 변경 요청 검증 등을 확인합니다. 수만 장 RAW의 실제 처리 시간과 제조사별 렌즈 인식률은 사용자의 라이브러리에서 별도 검증이 필요합니다. 기본 RAW 처리는 파일별 ExifTool 호출이므로 JPEG보다 느립니다.
